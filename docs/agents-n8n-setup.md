# LoanOS Agents — n8n Setup Guide

## Agent 5: Loan Milestone Communication Agent

Triggered by n8n when a loan hits a milestone in Arive. Drafts borrower + realtor emails and pushes them to Outlook as drafts.

### Endpoint

```
POST https://loanos.vercel.app/api/agents/milestone
Content-Type: application/json
```

### Required Payload Fields

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `loan_id` | string | ✅ | Arive loan ID |
| `milestone` | string | ✅ | One of the 7 values below |
| `borrower_name` | string | — | Full name |
| `borrower_email` | string | — | Skip draft if missing |
| `realtor_name` | string | — | Full name |
| `realtor_email` | string | — | Skip draft if missing |
| `property_address` | string | — | Used in email copy |

### Valid Milestone Values

| Value | Meaning |
|-------|---------|
| `application_received` | Application received and file opened |
| `processing` | File in active processing |
| `appraisal_ordered` | Appraisal has been ordered |
| `conditional_approval` | Conditional loan approval received from UW |
| `clear_to_close` | All conditions met — CTC issued |
| `closing_scheduled` | Closing date/time confirmed |
| `funded` | Loan funded and closed |

### Example Payload

```json
{
  "loan_id": "ARIVE-12345",
  "milestone": "clear_to_close",
  "borrower_name": "John Smith",
  "borrower_email": "john@example.com",
  "realtor_name": "Jane Doe",
  "realtor_email": "jane@realtyco.com",
  "property_address": "123 Oak St, Austin TX 78701"
}
```

### n8n Workflow Setup

1. **Trigger:** Arive webhook (or HTTP Request node polling Arive API)
2. **Map fields:** Use a Set or Code node to map Arive fields to the payload above
3. **HTTP Request node:**
   - Method: `POST`
   - URL: `https://loanos.vercel.app/api/agents/milestone`
   - Body: JSON payload from step 2
4. **Error handling:** Add an Error Trigger node → Slack/email notification

### Required Environment Variables (Vercel)

| Variable | Value |
|----------|-------|
| `ZAPIER_DISPATCH_WEBHOOK_URL` | Your Zapier webhook URL for Outlook draft creation |
| `DISPATCH_SECRET` | Bearer token configured in Zapier — sent as `Authorization: Bearer <secret>` |
| `ANTHROPIC_API_KEY` | Anthropic API key |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase service role key (not anon key) |

## Agent 1: Daily Command Center

Hit this each morning to get a prioritized action list generated by Claude.

### Endpoint

```
GET https://loanos.vercel.app/api/agents/daily-briefing
```

No authentication required (internal use only — do not expose publicly).

### Response Shape

```json
{
  "ok": true,
  "generatedAt": "2026-03-11T09:00:00.000Z",
  "summary": "3 loans are closing this week...",
  "top7": [
    {
      "rank": 1,
      "contact": "John Smith",
      "action": "Call to confirm closing time",
      "reason": "CTC issued yesterday, closing tomorrow at 2pm",
      "snippet": "Hey John — just confirming we're all set for tomorrow..."
    }
  ],
  "staleLeads": [...],
  "activeLoans": [...],
  "recentMilestones": [...],
  "realtorTouches": [...],
  "pendingDrafts": [...]
}
```

### Access from n8n (optional automation)

You can have n8n hit this each morning and send the `summary` + `top7` to your phone via SMS or Slack:

1. **Schedule trigger:** `0 8 * * 1-5` (8am weekdays)
2. **HTTP Request:** GET `https://loanos.vercel.app/api/agents/daily-briefing`
3. **Code node:** Format `summary` + top 3 actions as text
4. **SMS/Slack node:** Send to your number

### Frontend

Available at: `https://loanos.vercel.app/dashboard/briefing`

- Click **Run Briefing** to fetch and render the action list
- Check off items as you complete them — progress bar tracks completion
- Stats row shows count of stale leads, active loans, realtor touches due, pending drafts

## Database Tables (Migration 010)

Both tables are written by the service role key only. No user auth required.

### `loan_milestone_events`

One row per milestone received from n8n.

| Column | Type | Notes |
|--------|------|-------|
| `id` | UUID | PK |
| `loan_id` | TEXT | Arive loan ID |
| `milestone` | TEXT | Enum — 7 values |
| `borrower_name/email` | TEXT | Optional |
| `realtor_name/email` | TEXT | Optional |
| `raw_payload` | JSONB | Full webhook body |
| `processed_at` | TIMESTAMPTZ | Set when emails drafted |

### `milestone_communications`

One row per drafted email (up to 2 per event: borrower + realtor).

| Column | Type | Notes |
|--------|------|-------|
| `milestone_event_id` | UUID | FK → loan_milestone_events |
| `recipient_type` | TEXT | `borrower` or `realtor` |
| `recipient_email` | TEXT | |
| `subject` | TEXT | Claude-generated |
| `body` | TEXT | Claude-generated |
| `draft_pushed` | BOOLEAN | true once Zapier accepted |
| `draft_pushed_at` | TIMESTAMPTZ | Timestamp of successful push |
