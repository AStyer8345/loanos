## UI/UX Improvements

### Theme fragmentation — two design languages in simultaneous use
LoanOS currently has two distinct visual themes active at the same time:

| Dark (target) | Light (legacy) |
|---|---|
| `dashboard/page.tsx` | `briefing/page.tsx` |
| `performance/page.tsx` | `automations/page.tsx` |
| PipelineKPIs, TodoList, UrgentFlags | loans/page.tsx, contacts/page.tsx |
| DailyBriefingPanel, RecentActivity | EmailDraftPreview |
| TopNav (gradient dark) | marketing/page.tsx (Bloomberg CSS vars) |

**Marketing page** still uses old Bloomberg terminal CSS variables (`--gold`, `font-display`, `var(--border)`). CONTEXT.md notes this as a known gap: "Marketing page still uses Bloomberg/gold CSS vars — not yet migrated to light mode."

**Briefing page** (`/dashboard/briefing/page.tsx`) is full light theme (`bg-slate-50`, `bg-white` cards, `text-slate-900`) while the rest of the app leans dark. The standalone briefing page is reached from the dark top nav, creating a jarring transition.

**Recommendation:** Pick one theme and complete the migration. Given that the main dashboard, KPI cards, and pipeline views are already dark + IBM Plex Mono + gold accent — continue with dark as the target. Briefing page, automations, loans, and contacts pages need a dark pass.
