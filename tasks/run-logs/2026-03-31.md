## LESSONS_LEARNED

- **Stale .next cache** — On the local Mac build environment, stale `.next/types/` files can cause spurious TypeScript errors after large changes (social dashboard, automation panel). If build fails with ENOENT on pages-manifest or missing `.next/types/*.ts`, run `rm -rf .next` and rebuild. Vercel builds are unaffected (start clean each time).
- **`as any` with prior-line eslint-disable** — `grep -v "eslint-disable"` on `as any` lines ONLY catches same-line comments. Prior-line `eslint-disable-next-line` comments will still show as "unguarded" in this grep. True effective count requires checking the line before each hit. All current `as any` usages are correctly guarded.
