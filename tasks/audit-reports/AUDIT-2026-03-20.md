# LoanOS Audit Report — 2026-03-20

## 🔴 Fixed This Session

### Arive New Loan — null first_name crash (workflow `1tagvoU0UXtdDiMY`)
**Root cause:** Arive sent 4 webhooks on 2026-03-19 with null `firstName`. The contact upsert node body used `first_name: $json.firstName` — JavaScript's `JSON.stringify` serializes null as a literal `null`, which Supabase rejects because `contacts.first_name` has a NOT NULL constraint.

**Fix applied:** Added `|| ''` fallback for `first_name` and `last_name` in the "HTTP Request" (contact upsert) node body. Workflow was patched via n8n API and is live.

**New body expression (relevant excerpt):**
```
first_name: $("Extract Loan Fields").first().json.firstName || '',
last_name: $("Extract Loan Fields").first().json.lastName || '',
```

**No new errors since the 2026-03-19 burst.** Workflow is stable.
