## LESSONS_LEARNED

- **`as any` grep false positives — same-line vs preceding-line eslint-disable** — same-line `// eslint-disable-line` comments are missed by `grep -B1 "as any" | grep -v "eslint-disable"` because the -B1 check only looks at the previous line. contacts/page.tsx uses same-line format for its 3 instances. Both comment formats are valid — the raw count (10) includes all 10 properly suppressed casts. Don't alarm on count increases without checking comment style.
- **Dead `created_by` double auth round-trip pattern** — If a route calls `getOrganization()` (which internally calls `auth.getUser()`), check whether any subsequent direct `supabase.auth.getUser()` call is still necessary. Often the user object from inside `getOrganization()` is used for one additional field that's actually unused in the UI. Remove the second call and use `userId` directly.
