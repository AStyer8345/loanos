How should the Marketing tab be structured?

Three approaches — all show the same actions, different navigation patterns

A

3 Focused Tabs

SEND · TODAY · HISTORY

SEND = Rate Update + Newsletter (the two "publish something" actions). TODAY = day-specific task checklist. HISTORY = cadence health + activity log.

SEND
TODAY

▶ SEND NOW
RATE UPDATE 6d ago — overdue
Calls Netlify → generates email → Mailchimp → published
▶ GENERATE
NEWSLETTER Sent Mon
AI draft → Mailchimp + blog post on styermortgage.com

Pros

  • Clearest separation of concerns
  • SEND tab is what you open every week
  • TODAY + HISTORY rarely needed — out of the way

Cons

  • TODAY tab may feel redundant with the main Dashboard
B

Single Page, Anchored Sections

No tabs — scroll down through sections

Rate Update at top (always visible), Newsletter below it, then call list, then history at bottom. Anchor links jump to sections.

Pros

  • Everything visible without clicking tabs
  • Status strip shows all cadence health at a glance

Cons

  • Long page, more scrolling
  • Less structure — harder to "get to" things fast
C

Command + Detail Split

Left rail = what to do. Right panel = do it.

Left shows this week's tasks + cadence health. Right panel opens the active tool (Rate Update or Newsletter generator).

  • Clicking an item loads it in the right panel — no navigation

  • Left rail competes with the dashboard's existing overview
