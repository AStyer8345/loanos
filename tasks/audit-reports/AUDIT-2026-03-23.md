## Architecture Notes

### ✅ Daily Report False Positives Corrected

The 2026-03-22 daily report had two categories of false positives that need to be understood before future audits re-raise them:

**"Dark theme violations" in scenarios files** — All flagged occurrences were `bg-white/5` and `bg-white/10`. These are semi-transparent white hover overlays (5%/10% opacity), NOT solid white backgrounds. They are correct dark-mode hover states. The grep pattern `bg-white` matches these incorrectly. Only `bg-white[^/]` (solid white) or `bg-gray-100`, `bg-gray-50` would be real violations.

**"Potentially Unused Components" list** — The scan searched only `src/app/` but 8 of the 10 flagged components are imported within `src/components/` (TopNav, DashboardClient, OutreachChat). The only truly unused components were `EmailDraftPreview.tsx` and `ActivityTimeline.tsx` — both confirmed unused and deleted this session (see Completed Fixes).
