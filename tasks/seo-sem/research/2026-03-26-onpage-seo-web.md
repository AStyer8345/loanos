## Source 1: On-Page SEO: The Definitive Guide (Backlinko)
URL: https://backlinko.com/on-page-seo

Key findings:
- Keyword in title tag is still critical — use target keyword at START of title tag
- One priority keyword per title; Google handles semantic variations
- Keyword should appear in first 100 words of page content
- H1 must contain primary keyword — one H1 per page only
- In 2026, on-page SEO = clarity + context for users, search engines, AND AI systems (AI Overviews)
- Pages must be fast, crawlable, and semantically clear
- Product, pricing, and positioning must be consistent across every page surface

---

## Source 2: Core Web Vitals — Most Effective Optimization Methods (web.dev)
URL: https://web.dev/articles/top-cwv

Key findings:
- LCP target: ≤ 2.5 seconds (marks when main content has loaded)
- INP target: ≤ 200ms (measures responsiveness to user interactions)
- CLS target: < 0.1 (measures visual stability / unexpected layout shift)
- Tasks > 50ms on main thread = "long tasks" that block interaction responsiveness
- Back/forward cache (bfcache) significantly improves return visits — ensure pages are eligible
- Chrome UX Report + PageSpeed Insights + Search Console CWV report are primary measurement tools

## Source 3: Local SEO Schema Complete Guide (Search Engine Journal)
URL: https://www.searchenginejournal.com/how-to-use-schema-for-local-seo-a-complete-guide/294973/

Key findings:
- Mortgage brokers should use FinancialService → LocalBusiness schema hierarchy
- LocalBusiness markup covers: name, address, hours, phone, geo coordinates, service area
- MortgageLoan schema (schema.org v30.0, 2026-03-19) includes: amount, loanTerm, interestRate, annualPercentageRate, repayment specs
- Local landing pages + structured data = framework for AI search to surface business in map results / AI Overviews
- GeoCoordinates schema reinforces local relevance for Austin TX targeting
- JSON-LD is Google's preferred format for structured data implementation
