## VERIFICATION PROTOCOL

### 1. Draft Confirmation in Marketing Dashboard Queue
Confirm every approved post exists in the `social_drafts` Supabase table:
- [ ] Post exists with status `draft` in `social_drafts` (not published, not scheduled to auto-publish)
- [ ] Platform is correct (LinkedIn / Instagram / Facebook / Google)
- [ ] Scheduled date matches the spec (if set)
- [ ] Post copy matches what Reviewer approved — no truncation or encoding issues
- [ ] Image URLs are attached for visual posts (media_urls field)
- [ ] Reels video prompt or script is noted in agent_notes for video posts

For each post: log status as CONFIRMED or MISSING.

### 2. Functional Test
For each draft post:
- [ ] Preview the post content from the social_drafts table
- [ ] Link in post resolves correctly (if any link was included)
- [ ] Image renders correctly — not cropped wrong, not pixelated
- [ ] Hashtags do not contain typos or broken characters
- [ ] Character/word count displays within platform limits in the scheduling tool

### 3. Compliance Spot-Check
Top 3 items to verify on EVERY post that goes to QA:
- [ ] NMLS# 513013 is present on any post where rates are mentioned
- [ ] No guaranteed approval language slipped through (verify against final draft copy)
- [ ] Equal Housing Lender is present on visual posts that reference rates or loan products

### 4. Regression Check
Confirm that scheduling approved posts did not affect existing drafts:
- [ ] Previously scheduled posts are still in the queue (nothing deleted or overwritten)
- [ ] No duplicate posts created for the same platform + date combination
- [ ] Supabase REST API is accessible (not returning errors)
