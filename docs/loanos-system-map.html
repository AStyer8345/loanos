Migration From Current Stack → LoanOS

Phase 1
✗ Jungo / Salesforce — siloed, manual entry, limited API
✓ LoanOS Contacts — unified DB, syncs both ways, RLS-scoped
Documents
Phase 1
✗ ShareFile — manual request links, no automation, per-seat cost
✓ Supabase Storage — loan-scoped, borrower portal, auto-organize
Automations
Phase 1–2
✗ Zapier — limited steps, per-task pricing, no AI
✓ n8n + Claude — unlimited flows, self-hosted, AI-native
Pipeline Tracking
Phase 2

✓ LoanOS Pipeline — built for mortgages, TRID-aware, one screen
Rate Publishing
Phase 2

✓ LoanOS Rate Engine — one click → website + Mailchimp + social
Realtor Communication

✓ Realtor Portal — login, live status, PA letter pulls, referrals
