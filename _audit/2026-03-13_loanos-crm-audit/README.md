## Critical Bugs (Fix First)

1. **"Closed Borrowers" smart list returns 0 records** — queries `'Closed Client'` but canonical stage is `'Closed'`. 5-minute fix.
2. **`last_touch` renders raw ISO timestamp** — needs `toLocaleDateString()` formatting.
3. **CSV import is non-functional** — file input wired but no processing handler exists.
4. **`phone_mobile` vs `mobile_phone` schema duplication** — two separate columns from two import sources. Requires migration.
