Auth + Multi-Tenancy
Magic link auth via Supabase. Organization-based RLS across all 15+ tables. 53 migrations applied. NOT NULL hardened on 8 tables. Onboarding collects NMLS, phone, states licensed.
Supabase Auth RLS

Contacts
Unified contact DB — borrowers, realtors, vendors. CSV + MISMO import. AI-powered extraction from uploaded docs. Referred loan tracking for realtors. Activity log per contact.
Postgres RLS

Pipeline / Loans
Full loan lifecycle. Arive webhook sync (WF1/WF2). Auto-generated loan names. AUS results, originator comp. Loan detail page with borrower, terms, property, key dates, parties.
