## VERIFICATION PROTOCOL

### 1. Deployment Verification
Confirm the git push completed and Netlify deployed successfully:
```bash
cd /Users/adamstyer/Documents/Claude/styerteam-mortgage-site/
git log --oneline -5
git status
```
Confirm the most recent commit matches what Builder described.

Check Netlify deployment status if possible (Netlify auto-deploys on push to main).
If deployment failed — log to BLOCKERS.md and stop.

### 2. HTTP Status Verification
For every page modified or created — verify it returns HTTP 200:
```bash
curl -o /dev/null -s -w "%{http_code}" https://styermortgage.com/[path]
```

Expected: 200
Failure: 404, 301 to wrong URL, 500 → log to BLOCKERS.md

If site is not live or curl returns non-200 consistently — check local HTML files for structural errors instead.

### 3. Meta Tag Verification
For each modified page — verify meta tags are correct in the live page source:
```bash
curl -s https://styermortgage.com/[path] | grep -E "<title>|meta name=\"description\"|rel=\"canonical\""
```

Check:
- `<title>` matches the spec (correct keyword, under 60 chars)
- `<meta name="description"` matches the spec (150-160 chars)
- `rel="canonical"` present and pointing to correct self-referencing URL

### 4. Schema Validation
For each page with new schema markup:
```bash
curl -s https://styermortgage.com/[path] | grep -A 50 'application/ld+json'
```

Verify the JSON-LD block is present and well-formed.
Paste the schema into Google's Rich Results Test (https://search.google.com/test/rich-results) — confirm it validates.
If test URL is not accessible — validate JSON structure locally using `python3 -m json.tool` or equivalent.

### 5. Internal Link Verification
For each internal link added — verify it resolves:
```bash
curl -o /dev/null -s -w "%{http_code}" https://styermortgage.com/[link-path]
```
Expected: 200 for all internal links.

### 6. Core Web Vitals — Regression Check
If Builder modified any CSS, JS, or added heavy content:
- Run a PageSpeed Insights check on the modified page
- Confirm LCP, INP, CLS scores did not meaningfully degrade vs. baseline
- If no baseline exists, document current scores as the new baseline in `tasks/seo-sem/research/`

### 7. Compliance Spot-Check
Top 3 compliance items to verify in live page source:
1. NMLS #513013 present in footer HTML
2. No `<meta name="robots" content="noindex">` on any page that should be indexed
3. Equal Housing Lender text present in footer

### 8. Regression Check
Verify existing site is intact — nothing was accidentally broken:
```bash
curl -o /dev/null -s -w "%{http_code}" https://styermortgage.com/
curl -o /dev/null -s -w "%{http_code}" https://styermortgage.com/contact.html
```

Check:
- Homepage still loads (HTTP 200)
- Contact page still loads (HTTP 200) — form field names unchanged
- GTM container still present: `curl -s https://styermortgage.com/ | grep "GTM-"`
- Loan application link still correct: `curl -s https://styermortgage.com/ | grep "mslp.my1003app.com"`
